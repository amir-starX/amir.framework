فایل اصلی که در ریشه پروژه قرار داره هسته پروژه هست که قابلیت های جدیدی که به html و php اضافه میکنیم رو پردازش میکنه با کمک فایل فانکشن هاش که در مسیر amir.framework/php/function/index.php قرار داره انجام میدهد

این فریم ورک در مدریت داده چه در دیتا بیس چه خارج از دیتابیس کمک میکند که کد هایی را در اینده میبینیم

این فریمورک اینگونه کار میکند که شما فایل های php را در /php و فایل های html را درون /html قرار میدهید و همین کار رو با css و js هم انجام بدهید

ما در فریم ورک 3 دستور پایه و 4 دستور دیتا داریم

دستورات داخل html
لود کردن متغیر های پی اچ پی {=var1=}
اضافه کردن صفحه به صفحه فعلی {+page+}
رفتن به صفحه دیگر {++page++}

دستورات php
خواندن اطلاعات از دیتا بیس name =  database.users.20.name$
و برای نوشتن در دیتا بیس همین ساختار را مینویسید ولی جای متغیر را با ادرس دیتابیس عوض میکنید
(برای اتصال به دیتا بیس از فایل کانفیگ استفاده کنید)
و برای گرفتن داده از کاربر به تگ imput دو ویژگی با نام name و pclass اضافه کنید و به دکمه هم یک pclass اضافه کنید
که name اسم متغیری است که قرار است ان مقدار را نگه دارد
البته توجه کنید که اون متغیر باید از قبل وجود داشته باشد 
یعنی از قبل در فایل php خود ان را تعریف کرده باشید
